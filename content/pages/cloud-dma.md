## What Is Cloud DMA?

The product is a virtualization-based software solution that uses Hyper-V to create its supported environment.

Hyper-V is Microsoft's virtualization technology, allowing compatible Windows systems to run virtualized environments.

The license uses this technology as part of its configuration, helping organize the required environment around your existing Windows computer.

Rather than treating the setup as an ordinary standalone application, it brings together the necessary virtualization components into a dedicated configuration.

## How the Single-PC Setup Works

One of the defining aspects of this license is its single-PC configuration.

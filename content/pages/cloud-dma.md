# Cloud DMA for Game Cheats

A well-organized gaming setup starts with the right infrastructure.

Cloud DMA provides a specialized software environment designed around Hyper-V virtualization, bringing the supported configuration together on a single Windows PC.

For players using compatible cheat configurations, Cloud DMA is an important part of the overall setup.

Its single-PC approach makes it an interesting solution for players looking to build a dedicated environment without centering their setup around an additional physical computer.

This page covers the **Cloud DMA infrastructure license**—not the [Borderlands 3 cheat package](/) itself. Compare [Borderlands 3 pricing](/pricing/) and read the [setup guide](/guides/cloud-dma-setup/) when you are ready.

## What Is Cloud DMA?

Cloud DMA is a virtualization-based software solution that uses Hyper-V to create its supported environment.

Hyper-V is Microsoft's virtualization technology, allowing compatible Windows systems to run virtualized environments.

Cloud DMA uses this technology as part of its configuration, helping organize the required environment around your existing Windows computer.

Rather than treating the setup as an ordinary standalone application, Cloud DMA brings together the necessary virtualization components into a dedicated configuration.

## How the Single-PC Cloud DMA Setup Works

One of the defining aspects of Cloud DMA is its single-PC configuration.

The setup is designed around a compatible Windows computer with the necessary virtualization capabilities.

Hyper-V provides the virtualization foundation, while the Cloud DMA software and its supporting services form the complete environment.

This arrangement allows the supported setup to operate around one primary machine.

The important part is having the correct Windows edition, processor virtualization support and sufficient system memory before beginning.

Before setting up Cloud DMA, make sure your computer has the required hardware and Windows configuration.

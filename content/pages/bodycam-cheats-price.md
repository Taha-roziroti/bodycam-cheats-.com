# Bodycam cheats price, pricing plans, and what each tier includes

Choosing a Bodycam plan is mostly about access length: **30-day monthly** or **one-time lifetime**. Both cheat plans advertise the same ESP, aimbot, and weapon menu—this page lists the published **pricing**, what ships with each plan, and where to verify specs before checkout.

## Published offers (cheat access)

| Plan | Listed pricing | What you get |
|------|----------------|--------------|
| Monthly | **$35** for 30 days | Full cheat feature list; renews each billing cycle per checkout terms |
| Lifetime | **$150** one-time | Same feature list; no monthly renewal on the cheat license |

**Not included in either cheat plan:** the [$50 Cloud DMA lifetime license](/cloud-dma-for-bodycam/) (Hyper-V stack), optional HWID utility, GREENWARD, static server hosting, or AWS resources.

### Proof you can verify before paying

- On-page screenshots above show the same ESP and menu toggles referenced in checkout copy (warehouse ESP and indoor cyan boxes).
- Feature pages with additional captures: [aimbot bones and FOV guide](/bodycam-aimbot/), [ESP and chams guide](/bodycam-esp/).
- Pre-purchase answers on delivery, renewal, and Cloud DMA: [Bodycam FAQ on plans and checkout](/faq/).

## Plan fit and Windows requirements

Pick monthly if you want a short renewal window; pick lifetime if you prefer a single cheat payment. Either way, supported builds still require Windows 10/11, 8 GB+ RAM, a dedicated GPU, HVCI/Core Isolation/TPM/Secure Boot where listed, and Cloud DMA on supported stacks.

Use the [RAM, GPU, and HVCI checklist](/bodycam-requirements/) and [Hyper-V Cloud DMA guide](/guides/cloud-dma-setup/) so hardware and virtualization match the published setup order before you open checkout.

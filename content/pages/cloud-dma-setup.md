# DMA setup guide — Hyper-V requirements

Setting up a virtualization-based gaming environment becomes much easier when you understand the components involved.

This dma setup guide uses Windows Hyper-V to establish its dedicated environment, bringing together the virtualization technology and supporting services required by the supported configuration.

The setup is centered around one compatible Windows computer, making your existing hardware the foundation of the environment.

In this guide, we'll cover the essential Cloud DMA requirements, the role of Hyper-V and the main things to prepare before getting started.

## DMA setup: Hyper-V prerequisites

Cloud DMA is built around Microsoft's Hyper-V virtualization technology.

Hyper-V allows Windows systems to create and operate virtual machines, providing the foundation for the Cloud DMA configuration.

Instead of relying on a traditional physical-machine arrangement, the supported Cloud DMA setup uses this virtualization environment as part of its architecture.

Understanding how Hyper-V works is a useful first step when preparing your computer.

Your system needs to support hardware virtualization and run a compatible Windows edition with Hyper-V functionality.

## Step 1: Check Your Windows Version

The first step is identifying the Windows version installed on your computer.

The listed Cloud DMA operating system requirements include:

- Windows 10 64-bit.
- Windows 11 64-bit.
- A Windows edition that supports the required Hyper-V functionality.

Checking your Windows edition helps establish whether the virtualization platform is available on your current system.

You can find your Windows edition through Settings under System and About.

For a smooth setup process, make sure your Windows installation is up to date and your system is running the appropriate edition.

## Step 2: Check CPU Virtualization Support

Hardware virtualization is an important part of the Cloud DMA environment.

Your processor must support virtualization technology, and the relevant capability needs to be available to Windows.

You can check processor virtualization information through Windows Task Manager.

1. Open Task Manager.
2. Navigate to the Performance section.
3. Select CPU.
4. Locate the Virtualization information.

This provides a convenient way to view the virtualization capability exposed by your computer.

The processor and firmware configuration should support the requirements of the Cloud DMA setup.

## Step 3: Prepare Your System Memory

Virtualization uses system resources, making available RAM an important consideration.

The listed Cloud DMA requirements include a minimum of 8 GB RAM, with 16 GB recommended.

| Memory | Recommendation |
| --- | --- |
| 8 GB | Listed minimum |
| 16 GB | Recommended |
| Higher capacity | Useful for systems running additional applications |

Having adequate memory available gives the virtualization environment more room to operate alongside Windows and other applications.

For a dedicated gaming setup, 16 GB is a sensible target.

## Step 4: Understand the Hyper-V Environment

Hyper-V is the virtualization platform used as the foundation of Cloud DMA.

Once your Windows edition and processor capabilities are confirmed, you can review the Hyper-V configuration as part of preparing the system.

Windows provides Hyper-V through its operating system features on supported editions.

The Cloud DMA product instructions provide the relevant configuration details for the supported environment.

Following the documented sequence keeps the preparation process organized and ensures that the required components are considered together.
